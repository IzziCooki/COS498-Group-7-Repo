# Change text size and display scale on Windows 11

If text is too small to read comfortably, Windows 11 has two separate
settings — **text size** (changes only text) and **display scale**
(changes everything: text, icons, and apps).

## Make only text bigger

1. Open **Settings → Accessibility → Text size**.
2. Drag the **Text size** slider to the right.
3. Click **Apply**. The change takes a few seconds to appear.

This affects text in menus, File Explorer, Settings, and most apps.

## Make everything bigger (recommended for elderly users)

1. Open **Settings → System → Display**.
2. Find **Scale** under the **Scale & layout** heading.
3. Choose a percentage. **125%** is a good first step. **150%** is
   common on laptops with high-resolution screens.
4. Some apps may need to be restarted to look right.

## Increase brightness

In **Settings → System → Display**, drag the **Brightness** slider.

## Use the magnifier

To enlarge a small area temporarily, press **Windows key + plus (+)**
to open the Magnifier. Press **Windows key + Esc** to close it.

## Why text looks blurry after scaling

Some older apps do not handle scaling well and look fuzzy. Right-click
the app's shortcut, choose **Properties → Compatibility → Change high
DPI settings → Override high DPI scaling behavior**, and set it to
**System (Enhanced)**.
