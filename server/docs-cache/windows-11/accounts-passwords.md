# Microsoft account, sign-in, and passwords

## Changing your sign-in password

1. Open **Settings → Accounts → Sign-in options**.
2. Click **Password**, then **Change**.
3. Type your current password.
4. Type the new password twice and click **Next**.

If you are signed in with a Microsoft account, the password change
applies to all Microsoft services (Outlook, OneDrive, Xbox).

## Setting up a PIN

A PIN is a short code (usually 4-6 digits) that signs you into this
specific computer. It is faster and safer than a long password.

1. **Settings → Accounts → Sign-in options → PIN (Windows Hello)**.
2. Click **Set up** and follow the prompts.

## Using fingerprint or face recognition

If your computer has the right hardware:

1. **Settings → Accounts → Sign-in options**.
2. Click **Fingerprint recognition** or **Facial recognition**.
3. Follow the prompts to scan.

## Forgotten password

If you forgot your sign-in password:

* **Microsoft account** — reset at account.live.com on another device,
  then sign back in here.
* **Local account** — answer the security questions on the lock
  screen, or sign in as another administrator and reset it from
  **Settings → Accounts → Other users**.
