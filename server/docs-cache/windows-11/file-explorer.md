# File Explorer basics on Windows 11

File Explorer is the program that shows folders and files. It looks
like a small **yellow folder** icon in the taskbar.

## Opening File Explorer

* Click the folder icon in the taskbar at the bottom of the screen, or
* Press **Windows key + E** on the keyboard.

## The left side: Quick access

The left panel shows shortcuts to common places:

* **Home** — recent files and pinned folders.
* **Desktop** — items on your desktop.
* **Documents** — your personal documents folder.
* **Downloads** — files downloaded from a web browser.
* **Pictures**, **Music**, **Videos**.
* **OneDrive** — files synced to Microsoft's cloud.
* **This PC** — drives connected to the computer.

## Creating a new folder

1. Open the place where you want the folder.
2. Right-click empty space and choose **New → Folder**.
3. Type a name and press **Enter**.

## Renaming a file or folder

1. Click the file once to select it.
2. Press **F2** on the keyboard, or right-click and choose **Rename**.
3. Type the new name and press **Enter**.

## Searching for a file

There is a search box at the top right of File Explorer. Type part of
the file name. Results appear as you type.

## Recovering a deleted file

Deleted files go to the **Recycle Bin** on the desktop. Open it,
right-click the file, and choose **Restore**.
