# Run Windows Update

Windows Update keeps the computer secure by installing the latest
patches from Microsoft. Most updates download in the background, but
they need a restart to finish.

## Check for updates manually

1. Open **Settings → Windows Update**.
2. Click **Check for updates**.
3. If updates are found, they download automatically.
4. When prompted, click **Restart now** or **Schedule the restart**.

## Pause updates temporarily

If you cannot afford a restart right now:

1. **Settings → Windows Update**.
2. Click **Pause for 1 week** (or pick another duration).

Updates will resume automatically when the pause ends.

## Active hours (avoid surprise restarts)

To stop Windows from restarting while you are using the computer:

1. **Settings → Windows Update → Advanced options**.
2. Set **Active hours** to a window that covers your normal use, like
   8 AM to 10 PM.

Windows will not restart during active hours unless you say it can.

## When updates fail

If Windows Update gets stuck on the same percentage for hours:

1. Restart the computer once.
2. Run **Settings → System → Troubleshoot → Other troubleshooters →
   Windows Update**.
3. As a last resort, free up disk space — updates need at least 10 GB
   free.
