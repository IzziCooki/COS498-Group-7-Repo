# Dark mode and themes on Windows 11

Dark mode replaces the bright white background of menus, Settings,
and File Explorer with a dark gray. It can reduce eye strain at night.

## Turning on dark mode

1. Open **Settings → Personalization → Colors**.
2. Find **Choose your mode** at the top.
3. Set it to **Dark** for everything, or **Custom** to mix.

In **Custom** mode you can have:

* **Windows mode** — the taskbar and Start menu colors.
* **App mode** — colors inside apps like Settings and Edge.

## Changing accent color

Same screen — **Accent color** is the color used for the Start button,
notifications, and selected items.

* **Automatic** picks a color from your wallpaper.
* **Manual** lets you choose any color.

## Using a built-in theme

A theme bundles wallpaper + colors + sounds.

1. **Settings → Personalization → Themes**.
2. Click any theme to apply it.
3. Click **Browse themes** to download new ones from the Microsoft
   Store.

## High-contrast theme (for low vision)

If you need maximum contrast rather than just dark mode:

1. **Settings → Accessibility → Contrast themes**.
2. Pick **Aquatic**, **Desert**, **Dusk**, or **Night sky**.
3. Click **Apply**.
