# Connect to Wi-Fi on Windows 11

Wi-Fi is how the computer connects to the internet without a cable.

## Connecting to a new Wi-Fi network

1. Click the **network icon** at the bottom-right of the screen, near
   the clock. It looks like a small globe or a curved Wi-Fi fan.
2. Click the **Wi-Fi arrow** (the right-arrow next to the Wi-Fi tile).
3. A list of nearby Wi-Fi networks appears. Click the one you want.
4. Optional: check **Connect automatically** so the computer remembers
   the network.
5. Click **Connect** and type the Wi-Fi password.

## Forgetting a network

If you no longer want the computer to remember a Wi-Fi network:

1. Open **Settings → Network & internet → Wi-Fi**.
2. Click **Manage known networks**.
3. Click the network and choose **Forget**.

## When Wi-Fi will not connect

Try these in order:

* Toggle Wi-Fi off and back on from the network icon.
* Restart the computer.
* Forget the network and reconnect with the password.
* Restart the home router (unplug for 30 seconds, plug back in).

If none of those help, run **Windows network troubleshooter** under
**Settings → System → Troubleshoot → Other troubleshooters → Internet
Connections**.

## Airplane mode

Airplane mode turns off all wireless connections. The icon looks like
a small airplane. Click it on the network panel to toggle it.
