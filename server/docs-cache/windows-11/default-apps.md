# Set default apps on Windows 11

Windows opens files with the **default app** for that file type — for
example, .pdf files open in Edge by default. You can change this to
any installed app.

## Change the default browser

1. Open **Settings → Apps → Default apps**.
2. Type your preferred browser (Chrome, Firefox, etc.) into the
   search box.
3. Click the browser when it appears.
4. Click **Set default** at the top right of its detail page.

This changes the default for HTTP, HTTPS, and HTML.

## Change the default app for a specific file type

1. **Settings → Apps → Default apps**.
2. Scroll down and click **Choose defaults by file type**.
3. Find the extension (like `.pdf`) and click the current default.
4. Pick the app you want.

## Change defaults from File Explorer

1. Right-click any file with the type you want to change.
2. Choose **Open with → Choose another app**.
3. Pick the app and check **Always use this app to open .xxx files**.
4. Click **OK**.

## Reset defaults

If apps got jumbled and you want to start over:

1. **Settings → Apps → Default apps**.
2. Scroll to **Reset all default apps** and click **Reset**.
