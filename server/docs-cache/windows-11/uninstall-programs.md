# Uninstall a program on Windows 11

The cleanest way to remove software is through Settings or the Start
menu — never delete program folders directly.

## Through Settings

1. Open **Settings → Apps → Installed apps**.
2. Find the app in the list. Use the search box at the top to filter.
3. Click the **three dots** next to the app and choose **Uninstall**.
4. Confirm.

## Through the Start menu

1. Open **Start → All apps**.
2. Right-click the app and choose **Uninstall**.

## What if Uninstall fails?

* Some apps need you to be signed in as an administrator.
* If the app is open, close it first.
* Some legacy apps still use **Control Panel → Programs and
  Features**. Open Control Panel by typing it into Start search.

## Built-in apps you cannot remove

A handful of system apps (like Microsoft Edge core components) cannot
be uninstalled because Windows depends on them. The uninstall option
is grayed out for these.
