# Mouse, touchpad, and keyboard settings on Windows 11

## Mouse pointer speed

1. Open **Settings → Bluetooth & devices → Mouse**.
2. Drag the **Mouse pointer speed** slider.

A slower pointer is easier to control for users with shaky hands.

## Make the pointer bigger or change its color

1. **Settings → Accessibility → Mouse pointer and touch**.
2. Drag the **Size** slider.
3. Pick a **Mouse pointer style** — black, white, inverted, or a
   custom color.

## Switching primary button (left-handed)

1. **Settings → Bluetooth & devices → Mouse**.
2. Set **Primary mouse button** to **Right**.

## Touchpad gestures

On laptops with a precision touchpad:

* **Two-finger scroll** — slide two fingers up or down.
* **Pinch to zoom** — common in browsers and PDF readers.
* **Three-finger swipe up** — show all open apps (Task View).
* **Three-finger swipe down** — show the desktop.

Configure these in **Settings → Bluetooth & devices → Touchpad**.

## Sticky Keys (one-finger shortcuts)

If you cannot hold multiple keys at once:

1. **Settings → Accessibility → Keyboard**.
2. Turn on **Sticky Keys**.

Now Ctrl, Alt, Shift, and the Windows key stay pressed after one tap.
