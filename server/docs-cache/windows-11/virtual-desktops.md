# Virtual desktops and Task View on Windows 11

Virtual desktops let you have several "screens" of open apps without
needing more monitors — for example a desktop for personal browsing
and another for video calls.

## Opening Task View

* Click the **Task View** icon on the taskbar (looks like two
  overlapping rectangles), or
* Press **Windows key + Tab**.

Task View shows all open windows and a row of desktops at the bottom.

## Creating a new desktop

In Task View, click **New desktop** at the bottom-left, or press
**Windows key + Ctrl + D**.

## Switching between desktops

* Press **Windows key + Ctrl + Left/Right arrow** to flip between
  desktops.
* Or open Task View and click the desktop you want.

## Moving a window to another desktop

In Task View, drag the window's preview onto the desktop tile at the
bottom. You can also right-click a window preview and pick **Move to**.

## Renaming a desktop

In Task View, click the desktop's name at the bottom and type a new
name like "Work" or "Calls".

## Closing a desktop

In Task View, hover over the desktop tile and click the **X**. The
windows on that desktop move to the next desktop — they are not
closed.
