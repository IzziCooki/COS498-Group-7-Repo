# Back up and recover files on Windows 11

Backup is critical — hard drives fail, and ransomware encrypts files.

## Back up to OneDrive (built-in cloud backup)

1. Open **Settings → Accounts → Windows backup**.
2. Click **Set up syncing** under **OneDrive folder syncing**.
3. Choose which folders to back up — Desktop, Documents, Pictures.

You get 5 GB of OneDrive space free. Microsoft 365 subscriptions
include 1 TB.

## Back up to an external drive

1. Plug in an external USB hard drive.
2. Open **Settings → System → Storage → Advanced storage settings →
   Backup options**.
3. Click **Add a drive** under **Back up using File History**.
4. Pick the external drive.

File History backs up Documents, Pictures, Music, Videos, and Desktop
folders every hour automatically.

## Restore a file from File History

1. **Settings → System → Storage → Backup options → Restore files
   from a current backup**.
2. Browse the timeline at the bottom of the window.
3. Select the file and click the **green Restore button**.

## System Restore (rolls back Windows itself)

System Restore puts Windows back to an earlier state without touching
personal files. Use it when a recent update or driver caused trouble.

1. Type `Create a restore point` into the Start search box and open it.
2. Click **System Restore**.
3. Pick a restore point from before the problem started.
4. Click **Next** and **Finish**. The computer restarts.
