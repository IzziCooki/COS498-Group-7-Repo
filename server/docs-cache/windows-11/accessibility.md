# Accessibility settings on Windows 11

Windows 11 has a single hub for accessibility under **Settings →
Accessibility**.

## Vision

* **Text size** — drag the slider to make all text bigger.
* **Visual effects** — turn off animations to reduce motion sickness.
* **Mouse pointer and touch** — make the cursor larger and a different
  color so it is easier to see.
* **Color filters** — built-in filters for color blindness.
* **Contrast themes** — high-contrast themes for low vision.
* **Magnifier** — turn on with **Windows key + plus (+)**, off with
  **Windows key + Esc**.
* **Narrator** — built-in screen reader. Turn on with **Windows key +
  Ctrl + Enter**.

## Hearing

* **Audio** — turn on **Mono audio** to combine left and right channels
  so you do not miss audio in one ear.
* **Captions** — turn on automatic captions for videos and calls.

## Mobility

* **Speech** — voice control with **Windows key + H**.
* **Eye control** — for users with assistive eye-tracking hardware.
* **Keyboard** — turn on **Sticky Keys**, **Filter Keys**, or **On-
  screen keyboard**.
* **Mouse** — control the pointer with the numeric keypad.

## Quick toggles for the most-used features

Press **Windows key + U** to jump straight to Accessibility settings.
