# Settings overview on Windows 11

The Settings app is where most of the computer's options live — Wi-Fi,
display, sound, accounts, and Windows Update.

## How to open Settings

Click **Start**, then click the gear-shaped **Settings** icon. You can
also press **Windows key + I** to open Settings directly.

## What is in Settings

Settings is organized into categories on the left side:

* **System** — display, sound, notifications, power, storage.
* **Bluetooth & devices** — Bluetooth, printers, mouse, keyboard.
* **Network & internet** — Wi-Fi, Ethernet, VPN.
* **Personalization** — wallpaper, colors, themes, taskbar.
* **Apps** — installed programs, default apps, startup apps.
* **Accounts** — your sign-in info, family settings, work accounts.
* **Time & language** — clock, region, languages.
* **Accessibility** — text size, magnifier, narrator, contrast.
* **Privacy & security** — Windows Security, app permissions.
* **Windows Update** — get the latest fixes from Microsoft.

## Searching settings

There is a search box at the top of the Settings window. Type what you
are looking for, like "screen brightness" or "default browser", and
matching settings appear.

## When Settings does not open

If clicking the gear icon does not open Settings, restart the computer
once. If it still does not open, sign out and back in, or run **System
File Checker** from a command prompt as administrator: `sfc /scannow`.
