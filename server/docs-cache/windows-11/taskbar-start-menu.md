# Taskbar and Start menu on Windows 11

The **taskbar** is the bar at the bottom of the screen. The **Start
menu** is the panel that appears when you click the Windows logo.

## Opening Start

Click the **Windows logo** in the middle (or left) of the taskbar, or
press the **Windows key** on the keyboard.

## Pinning an app to Start

1. Open Start.
2. Click **All apps** at the top right.
3. Right-click the app and choose **Pin to Start**.

## Pinning an app to the taskbar

1. Find the app on Start or in **All apps**.
2. Right-click the app and choose **Pin to taskbar**.

The app's icon now sits permanently on the taskbar.

## Moving the Start button to the left

By default Start is centered. To move it to the left like older
Windows versions:

1. Open **Settings → Personalization → Taskbar**.
2. Expand **Taskbar behaviors**.
3. Set **Taskbar alignment** to **Left**.

## Hiding the taskbar

In **Settings → Personalization → Taskbar → Taskbar behaviors**, turn
on **Automatically hide the taskbar**. Move the mouse to the bottom of
the screen to make it reappear.
