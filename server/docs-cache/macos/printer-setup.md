# Add a printer on Mac

## USB printer

1. Plug the printer into the Mac with a USB cable.
2. Turn the printer on.
3. macOS usually adds it automatically. The first time you print, it
   will appear in the print dialog's **Printer** dropdown.

If macOS asks to download printer software, allow it.

## Wi-Fi printer

1. Make sure the printer is on the same Wi-Fi network as the Mac.
2. Open **System Settings → Printers & Scanners**.
3. Click **Add Printer, Scanner, or Fax…**.
4. Wait for the printer to appear in the list under the **Default**
   tab.
5. Click the printer and click **Add**.

If the printer does not appear, click the **IP** tab and type the
printer's IP address (you can find it printed on the printer's setup
page or in the router's device list).

## AirPrint vs traditional driver

Most modern printers support **AirPrint** — they work with the Mac
without installing any extra software. The driver dropdown shows
**AirPrint** automatically. If your printer is not AirPrint-capable,
the Mac downloads a driver from Apple. Avoid downloading drivers
from third-party sites.

## Setting a default printer

In **System Settings → Printers & Scanners**, set the **Default
printer** dropdown to the printer you want.

## Clearing a stuck print job

1. **System Settings → Printers & Scanners**.
2. Click the printer.
3. Click **Printer Queue…**.
4. Select the stuck job and click the **X** in its row.
