# Appearance, dark mode, and Night Shift on Mac

## Switching between light and dark mode

1. Open **System Settings → Appearance**.
2. Pick **Light**, **Dark**, or **Auto** (light during the day, dark
   at night).

Most modern apps respect this choice. Some older apps stay light
regardless.

## Accent color

The accent color is used for buttons, selections, and highlights.

In the same Appearance panel, choose any of the colored circles —
**Multicolor** uses the per-app default.

## Highlight color

Choose the color of selected text in **Appearance → Highlight color**.

## Reduce motion (less animation)

If animations cause discomfort:

1. **System Settings → Accessibility → Display**.
2. Turn on **Reduce motion**.

## Night Shift

Night Shift makes the screen warmer (less blue) in the evening, which
can help you wind down.

1. **System Settings → Displays → Night Shift**.
2. Pick **Sunset to Sunrise** for an automatic schedule, or set a
   custom schedule.
3. Drag **Color temperature** toward **More warm** for stronger
   effect.

## True Tone

True Tone subtly adjusts the screen's white balance to match the
room's lighting. Toggle in **Displays**. It is on by default and most
people find it pleasant.
