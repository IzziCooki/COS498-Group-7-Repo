# Connect to Wi-Fi on Mac

## Connecting to a new network

1. Click the **Wi-Fi icon** in the menu bar at the top-right of the
   screen. The icon looks like a small fan of curved lines.
2. If Wi-Fi is off, click the toggle to turn it on.
3. Choose the Wi-Fi network from the list.
4. Type the password and click **Join**.

The Mac remembers the network and joins automatically when in range.

## Forgetting a network

1. Open **System Settings → Wi-Fi**.
2. Find the network under **Known Networks**.
3. Click the **three dots** next to its name and choose **Forget This
   Network**.

## When Wi-Fi will not connect

Try these in order:

* Click the Wi-Fi icon, toggle Wi-Fi off and back on.
* Open **System Settings → Wi-Fi**, click **Details** next to the
  network, and re-enter the password.
* Restart the Mac.
* Restart the home router (unplug for 30 seconds, plug back in).
* Open **Wireless Diagnostics** by holding **Option** and clicking
  the Wi-Fi icon, then choose **Open Wireless Diagnostics…**.

## Connecting to a hidden network

If the Wi-Fi network does not broadcast its name:

1. Click the Wi-Fi icon.
2. Click **Other Networks**.
3. Click **Other…** at the bottom.
4. Type the network name (SSID) and password.
