# Set the default web browser and email app on Mac

When you click a link, macOS opens it in the **default browser**.
When you click a `mailto:` link, macOS opens the **default email
client**.

## Default web browser

1. Open **System Settings → Desktop & Dock**.
2. Scroll to **Default web browser**.
3. Choose Safari, Chrome, Firefox, Edge, or any installed browser.

## Default email client

This setting lives inside the Mail app, not System Settings.

1. Open **Mail**.
2. Go to **Mail → Settings → General**.
3. Pick a different app from **Default email reader**.

## What happens when the default browser is uninstalled

If the default browser is no longer installed, macOS falls back to
**Safari**. Set a new default before uninstalling the previous one to
avoid surprises.

## Why a setting keeps reverting

A few apps re-prompt for default-browser status on every launch.
Decline if you do not want them as default — Apple's setting in
**Desktop & Dock** is what actually controls the default.
