# Spotlight search on Mac

Spotlight is the Mac's universal search. Use it to find files, open
apps, do quick math, and look up definitions.

## Opening Spotlight

Press **Command + Space**. A search box appears at the top of the
screen.

## What you can search for

* **App names** — type **Mail**, **Safari**, **Calculator**, etc.,
  then press **Return** to launch.
* **Documents** — type the file name or words from inside the file.
* **Settings** — type **Wi-Fi**, **Sound**, **Bluetooth**, etc.
* **Math** — type `(125 * 3) + 7`, the answer appears.
* **Conversions** — `100 USD in EUR`, `5 miles to km`.
* **Definitions** — type a word and look for the dictionary preview.
* **Web search** — at the bottom of results, **Search Web for…**.

## Refining results

Spotlight previews each result on the right. Use the up/down arrows
to scroll.

To open the highlighted item:
* Press **Return** to open it.
* Press **Command + Return** to show it in Finder instead of opening.

## Hiding categories you do not use

1. **System Settings → Spotlight**.
2. Uncheck categories like **Movies**, **Sports**, **Stocks** if you
   never search those.
