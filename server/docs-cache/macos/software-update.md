# Software Update on Mac

Software Update keeps macOS, Apple's apps, and security patches
current.

## Check for updates manually

1. Open **System Settings → General → Software Update**.
2. Wait while macOS checks Apple's servers.
3. If updates are available, click **Update Now** or **Upgrade Now**.

## The difference between Update and Upgrade

* **Update** — minor patches within the same macOS version, like
  going from 15.2 to 15.3.
* **Upgrade** — major version change, like going from macOS Sonoma
  to macOS Sequoia.

Upgrades take longer (30-60 minutes) and may require more disk space.
Back up before upgrading.

## Automatic updates

In the same screen, click the **i** next to **Automatic updates** to
configure:

* **Check for updates** — recommend on.
* **Download new updates when available** — recommend on.
* **Install macOS updates** — your choice. Off means you control the
  timing of restarts.
* **Install application updates from the App Store** — recommend on.
* **Install Security Responses and system files** — strongly
  recommend on.

## Update is stuck or failing

* Free up disk space — major upgrades need 30-50 GB free.
* Restart the Mac and try again.
* Connect to a wired Ethernet network instead of Wi-Fi if downloads
  are slow.
