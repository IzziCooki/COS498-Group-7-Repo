# System Settings overview on macOS

System Settings is where most Mac options live. (On older macOS it
was called **System Preferences**.)

## How to open System Settings

* Click the **Apple menu** (Apple icon) at the top-left of the screen
  and choose **System Settings**, or
* Press **Command + Space** to open Spotlight, type
  **System Settings**, and press **Return**.

## Where things live

System Settings has a sidebar on the left with these sections:

* **Wi-Fi** — wireless networks.
* **Bluetooth** — wireless device pairing.
* **Network** — Ethernet, VPN, Firewall.
* **General** — About, Software Update, Storage, Sharing.
* **Appearance** — light/dark mode and accent color.
* **Accessibility** — vision, hearing, and motor accommodations.
* **Sound** — volume, output, and input devices.
* **Displays** — resolution, brightness, Night Shift.
* **Privacy & Security** — app permissions, FileVault, Touch ID.
* **Apple ID** — iCloud, App Store, Find My.

## Searching System Settings

There is a search box at the top of the sidebar. Type what you are
looking for — for example "scroll direction" or "default browser".
