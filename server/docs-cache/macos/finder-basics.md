# Finder basics on Mac

Finder is the macOS equivalent of File Explorer. It is the program
running whenever you see a desktop or folder window. Its icon is the
**blue and white face** at the left end of the Dock.

## Opening a Finder window

* Click the **Finder** icon in the Dock, or
* Press **Command + N** when Finder is the active app.

## The sidebar

The left side of the window shows your favorite places. By default:

* **AirDrop** — share files with nearby Apple devices.
* **Recents** — files opened recently.
* **Applications** — installed apps.
* **Desktop**, **Documents**, **Downloads** — your personal folders.
* **iCloud Drive** — files synced to iCloud.

You can drag any folder into the sidebar to make it always visible.

## View styles

Look for the four small icons at the top of the Finder window:

* **Icon view** — large pictures.
* **List view** — sortable columns.
* **Column view** — folders cascade left to right.
* **Gallery view** — preview the highlighted file.

## Creating a new folder

* Press **Shift + Command + N**, or
* Right-click empty space and choose **New Folder**.

## Searching

The search box at the top right of Finder searches your whole Mac. To
limit the search to the current folder, after pressing search, click
the folder name shown right under the search bar.

## Deleting a file

Drag the file to the **Trash** in the Dock, or select it and press
**Command + Delete**.
