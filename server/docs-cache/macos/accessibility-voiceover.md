# Accessibility and VoiceOver on Mac

macOS has a single hub for accessibility under **System Settings →
Accessibility**.

## Vision

* **Display** — make text bigger, increase contrast, reduce motion,
  invert colors.
* **Zoom** — magnify part of the screen with a keyboard shortcut.
* **VoiceOver** — full screen reader that speaks every interface
  element. Toggle with **Command + F5**.
* **Spoken Content** — have the Mac read selected text out loud.

## Hearing

* **Audio** — flash the screen instead of beeping, play stereo as
  mono, balance left/right channels.
* **Captions** — built-in caption preferences for movies and calls.
* **RTT** — Real-time text for phone calls.

## Motor

* **Voice Control** — fully control the Mac by speaking. Turn on in
  Accessibility → Voice Control.
* **Keyboard** — Sticky Keys, Slow Keys, accessibility keyboard.
* **Pointer Control** — alternate ways to control the cursor (head
  pointer, switch control).

## VoiceOver basics

After turning VoiceOver on with **Command + F5**:

* **VO key** — by default this is **Control + Option** (held
  together). Almost every VoiceOver shortcut starts with VO.
* **VO + A** — start reading from the current location.
* **VO + Right Arrow / Left Arrow** — move to the next/previous item.
* **VO + Space** — activate (click) the focused item.

The first time VoiceOver runs, it offers an interactive tutorial.
