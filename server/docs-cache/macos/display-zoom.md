# Make text and icons bigger on Mac

## Making the whole screen show bigger items

1. Open **System Settings → Displays**.
2. Under **Resolution**, choose **Larger Text** (older macOS calls
   this **Default for display**).

This makes everything on screen — text, icons, buttons — physically
larger.

## Making just text bigger in apps

* **Mail** — choose **Mail → Settings → Fonts & Colors** and pick a
  larger message font.
* **Messages** — Messages → Settings → General → Text size slider.
* **Safari** — press **Command + plus (+)** to zoom in, **Command +
  0** to reset.
* **Notes** — Notes → Settings → Default text size.

## Make the cursor easier to see

In **System Settings → Accessibility → Display**:

* Toggle **Pointer size** larger.
* Turn on **Shake mouse pointer to locate** — wiggling the mouse
  briefly enlarges the pointer.

## Use Zoom to magnify part of the screen

Zoom enlarges a portion of the screen on demand.

1. **System Settings → Accessibility → Zoom**.
2. Turn on **Use keyboard shortcuts to zoom**:
   * **Option + Command + 8** — toggle Zoom.
   * **Option + Command + plus (=)** — zoom in.
   * **Option + Command + minus (-)** — zoom out.
