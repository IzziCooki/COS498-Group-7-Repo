# PC Pal Extrinsic Evaluation — Researcher Kit

Everything needed to run the user study described in
[../sample_conversations.json](../sample_conversations.json) and the project
notebook (Step 4).

## Files

| File | Purpose |
|---|---|
| `consent.md` | Plain-language acknowledgment to send participants ahead of the session. |
| `script.md` | Verbatim read-aloud script for the researcher. Run in Zoom with this open. |
| `success_rubric.md` | Pre-registered binary success criteria per task. **Lock before participant 1.** |
| `task_log_template.csv` | Per-task quantitative log. Copy to `task_log.csv` and fill during sessions. |
| `build_forms.gs` | Google Apps Script that builds the two surveys. Run once. |

After the study runs, expected additions:

| File | Source |
|---|---|
| `task_log.csv` | Filled-in copy of the template, one row per task-run. |
| `responses.csv` | Per-task survey export from Google Forms. |
| `post_responses.csv` | Post-session survey export. |
| `interviews_raw.md` | Transcribed quotes from the post-session interviews. |
| `interviews.md` | Top 3 themes + representative quotes (cell 20 in the notebook reads this). |
| `transcripts/` | Conversation transcripts pulled from PC Pal History tab. |
| `likert.png` | Plot generated by notebook cell 20. |

## Quick start

1. Run `build_forms.gs` in Apps Script (instructions inside the file). Note the
   two form URLs and the entry IDs it logs.
2. Construct pre-fill URLs for each (participant × task × condition) — see
   `script.md` for the pattern. You'll have 5 participants × 6 task-runs = 30
   pre-filled per-task URLs and 5 post-session URLs.
3. Read `script.md` end-to-end. Pilot with one teammate. Time the protocol.
4. Lock `success_rubric.md` (commit it, don't edit after).
5. Run sessions. Fill `task_log.csv` row-by-row.
6. After all sessions: export Form CSVs, transcribe interviews, run notebook
   cell 20 against this directory.

## Counterbalance assignment

| Participant | First condition | Second condition |
|---|---|---|
| P01 | PC Pal | ChatGPT |
| P02 | ChatGPT | PC Pal |
| P03 | PC Pal | ChatGPT |
| P04 | ChatGPT | PC Pal |
| P05 | PC Pal | ChatGPT |

Within a condition, run the tasks in the order: wifi → scam → freeform. (Easy
→ hard.)
